# Phase 2G-M10-C Companion Reaction Flow Preview

Stand: 2026-06-06

Diese Preview ist Dokumentationsmaterial fuer Phase 2G-M10-C. Sie zeigt, wie
Tali/Vori den Depth-/Container-Flow

```text
Haus/Kueche -> Schublade -> Besteck
```

emotional begleiten kann, ohne die Challenge zu loesen, Druck zu erzeugen oder
eine finale Companion-UX freizugeben.

## Dateien

- `01_companion_reaction_timeline.png`
  - Timeline vom Curiosity Cue bis zum optionalen naechsten Ziel.
- `02_success_error_idle_reactions.png`
  - Drei Reaktionspfade: Success, Error und Idle / Hint.
- `03_companion_boundaries.png`
  - Grenzen fuer Companion-Verhalten: motivieren ja, loesen/nerven/Druck nein.

## Prueffazit

Die Preview macht sichtbar, dass Tali/Vori als emotionaler Motivationsanker
funktionieren kann, ohne die Mini-Challenge zu ueberlagern. Die wichtigsten
Momente sind Curiosity Cue, sanfter Hinweis, Erfolg, freundliche Korrektur und
optionales naechstes Ziel.

Kleine visuelle Auffaelligkeit: In `01_companion_reaction_timeline.png` sind
einzelne Labels sehr nah am Kartenrahmen. Das ist fuer diesen
Dokumentationsblock nicht blockierend, bleibt aber als Quality Note
dokumentiert.

## Grenzen

M10-C entscheidet noch nicht:

- finale Companion-UX,
- Companion-Implementierung,
- Voice-/Audio-Ausgabe,
- Animation oder Rive/FX,
- finale Companion-Texte,
- Tali/Vori-Asset-Produktion,
- allgemeines Container-System,
- Code,
- App-Integration,
- Asset-Freigabe,
- `frame_started`.

Fuer spaetere Previews gilt Text-Containment als Qualitaetsregel: Texte sollen
sichtbar innerhalb ihrer Karten, Rahmen oder Panels bleiben, und lange Labels
muessen umgebrochen, gekuerzt oder mit groesserer Box dargestellt werden. In
diesem Block werden keine PNGs neu erzeugt oder geaendert.
