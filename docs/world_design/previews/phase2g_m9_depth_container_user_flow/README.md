# Phase 2G-M9 Depth Container User Flow Preview

Status: `Dokumentations-/Previewmaterial erzeugt`

## Zweck

Diese Preview zeigt eine vereinfachte Nutzer-/Produktansicht fuer den
Depth-/Container-Flow:

```text
Haus/Kueche -> Schublade -> Besteck
```

Sie beantwortet die Frage, wie Lernen erlebt werden kann, wenn der Nutzer von
einem Bereich in ein Objekt hineinzoomt, einen Container oeffnet und dort eine
kleine Lern-Challenge loest.

## Dateien

- `01_depth_flow_storyboard.png`
  - Storyboard von Kueche, Schublade, Fokus, geoeffnetem Container,
    Mini-Challenge, Feedback/Reward und naechstem Ziel.
- `02_depth_level_stack.png`
  - Ebenenmodell von `IslandView` bis `DetailInteractionView` mit markiertem
    Beispielpfad.
- `03_interaction_reward_loop.png`
  - Vereinfachter Loop von Entdecken, Oeffnen, Erkennen, Loesen, Feedback,
    Sammeln/Verbessern und naechstem Ziel.

Die Dateien wurden als einfache Diagramm-/Preview-Bilder mit der lokalen
`.venv-tools`-Python-Toolchain und Pillow erzeugt.

## Kurzes Prueffazit

Die Preview ist als Dokumentationsmaterial geeignet:

- Der Nutzerflow ist klarer als die technische M7-B-Greybox.
- Der Container reduziert visuelle Ueberladung.
- Kleine Objekte erscheinen erst in der passenden Tiefe.
- Die Mini-Challenge ist sichtbar Teil des Flows.
- Feedback, Reward Moment und naechstes Ziel sind erkennbar.
- Die Bilder wirken diagrammatisch und nicht wie finale App-Screens.

## Sichtbare Risiken

- Die Preview ist bewusst schematisch und noch nicht emotional oder atmosphaerisch.
- Die Kueche ist nur ein Beispiel, keine freigegebene Interior-Architektur.
- Die genaue Challenge-Form bleibt offen: Tap, Audio, Drag-and-drop oder
  Zuordnung muessen spaeter getrennt entschieden werden.
- Tali/Vori-Reaktion ist nur als Produktmoment markiert, nicht implementiert.
- Weitere Flows wie Schule/Federmappe oder Hafen/Bootskajute fehlen noch.

## Grenzen

Diese Preview ist:

- kein Spielasset,
- keine finale Kunst,
- keine finale UI,
- keine App-Integration,
- keine Codefreigabe,
- keine Assetfreigabe,
- keine Freigabe fuer `frame_started`,
- keine produktive Bau-/Lernlogik.
