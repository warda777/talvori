# Phase 2G-M10 Emotional Product Flow Preview

Stand: 2026-06-06

Diese Preview ist Dokumentationsmaterial fuer Phase 2G-M10. Sie erweitert den
M9-Beispiel-Flow

```text
Haus/Kueche -> Schublade -> Besteck
```

um mehr Produktgefuehl: Neugier, kleine Entdeckung, Mini-Challenge, positives
Feedback, Reward Moment, leichte Tali/Vori-Praesenz und ein freiwilliges
naechstes Ziel.

## Dateien

- `01_emotional_storyboard.png`
  - 8-Panel-Storyboard fuer Kueche, Curiosity Cue, Tap, Oeffnen, Objekte,
    Mini-Challenge, Feedback und Reward.
- `02_emotion_motivation_beats.png`
  - Beat-Uebersicht fuer Curiosity Cue, User Action, Reveal, Challenge,
    Success Feedback, Reward und Next Goal.
- `03_tali_vori_light_reaction_concept.png`
  - Leichter Companion-Reaktionsablauf als Vorgeschmack auf M10-C.

## Prueffazit

Die Preview ist emotionaler und spielnaeher als M9, bleibt aber klar
diagrammatisch. Sie zeigt, dass der Nutzer nicht nur eine Objektliste
betrachtet, sondern eine Schublade entdeckt, oeffnet, eine kleine Aufgabe
loest, positives Feedback erhaelt und freiwillig zum naechsten Ziel wechseln
kann.

## Grenzen

M10 entscheidet noch nicht:

- finale UI,
- finale Kunst,
- Sound-/FX-Design,
- Challenge-Art,
- Companion-System,
- Container-System fuer alle Themen,
- Code,
- App-Integration,
- Asset-Freigabe,
- `frame_started`.
