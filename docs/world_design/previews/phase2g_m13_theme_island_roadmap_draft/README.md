# Phase 2G-M13 ThemeIsland Roadmap Draft Preview

Stand: 2026-06-06

## Zweck

Diese Preview-Dateien visualisieren den ersten nicht-finalen
ThemeIsland-Roadmap-Draft aus M13. Sie zeigen Roadmap-Wellen, Early-
Kandidaten, Gates und Scope-Risiken.

Die Dateien sind:

- Dokumentationsmaterial,
- Planungs-Preview,
- keine finale ThemeIsland-Roadmap,
- keine finale UI,
- keine Spielassets,
- keine App-Integration,
- keine Codefreigabe,
- keine Assetfreigabe,
- keine Freigabe fuer `frame_started`.

## Dateien

1. `01_theme_island_roadmap_waves.png`
   - zeigt Foundation, Expansion Wave 1, Expansion Wave 2, System-Heavy Wave
     und Sensitive/Special Wave.

2. `02_early_island_candidate_cards.png`
   - zeigt Roadmap-Karten fuer Zuhause/Alltag, Schule/Lernen und Garten/Natur
     nah.

3. `03_roadmap_gate_flow.png`
   - zeigt M12 Foundation -> M13 Draft -> Required Gates -> Later Decision.
   - markiert klar: kein Code, keine Assets, keine finale Roadmap, keine
     Runtime-Konfiguration.

4. `04_risk_and_scope_map.png`
   - zeigt, warum Early, Mid, Late/System-Heavy und Sensitive/Special nicht
     gleichzeitig geplant oder umgesetzt werden duerfen.

## Prueffazit

Die Previews sind als Roadmap-Draft lesbar und trennen Foundation, Expansion,
System-Heavy und Sensitive/Special Themen. Die Early-Kandidaten bleiben
nachvollziehbar, aber nicht implementierungsbereit. Gates und Grenzen sind
sichtbar.
